办公协作与学术检索

远程会议、云文档、代码仓库和文献数据库对稳定性和延迟更敏感。云魂普通线路池可满足日常办公；需要固定出口或定制分流时，可使用团队版的企业路由说明。

游戏与实时通讯

旗舰版包含 IPLC 专线游戏加速优化，适合对丢包和抖动更在意的对战与语音场景。请在客户端中优先选择标注游戏或专线的节点，并关闭不必要的全局规则以降低功耗。

多设备同时在线

手机、电脑和平板同时使用时，请对照套餐设备上限。基础版 3 台、旗舰版 5 台、团队版 20 台。超出上限会导致新会话被挤下线，属于套餐规则而非故障。

操作说明

一、选择套餐并获取订阅

  1. 对照流量、设备数与是否需要 IPLC / 原生解锁，选择基础版、旗舰版或团队版。
  2. 完成订购后进入用户中心，复制机场订阅地址（通常为一行 HTTPS 链接）。
  3. 不要在聊天工具里反复转发订阅，以免链接被滥用后被重置。

二、安装客户端并导入

  1. 按系统打开「客户端选择」，安装对应应用。
  2. 在客户端中选择「从 URL 导入 / 订阅管理」，粘贴云魂订阅并命名为「云魂」。
  3. 允许客户端更新节点。若更新失败，检查系统时间、本地代理循环和订阅是否过期。

三、连接与分流

  1. 日常浏览建议使用规则模式，仅对境外域名走代理。
  2. 流媒体选择解锁标注节点；游戏选择 IPLC 或低延迟专线。
  3. 若某个节点超时，切换同区域其他节点，不必反复重装客户端。

四、安全与官方身份

云魂官方网站用于公布套餐、客户端指引与操作说明。任何要求你二次验证码、远控桌面或安装来源不明加速器的请求，都不属于官方流程。节点与线路会随骨干网调整，以客户端实时列表为准。

常见问题

云魂是什么？和普通 VPN 有何不同？

云魂是机场订阅型网络加速服务：一份订阅可在多款客户端中使用，节点按区域与用途分组。相对单一出口的传统 VPN，机场更强调可切换线路、规则分流和流媒体解锁。官网提供套餐对照与客户端选择，便于按设备数和流量选型。

第一次使用应该下载哪个客户端？

Windows 与 Android 优先 Clash Meta 系；macOS 可用 ClashX Meta 或 Stash；iOS 常用 Shadowrocket、Stash 或 Quantumult X。选好客户端后，只需导入云魂订阅，不必为每个节点单独填写服务器。安装包请走官网下载指引，避免修改版。

基础版、旗舰版和团队版怎么选？

轻度网页与偶尔看视频选基础版（100GB / 3 设备）。需要原生流媒体、游戏专线和优先工单选旗舰版（300GB / 5 设备）。工作室或多终端统一出口选团队版（1000GB / 20 设备，含 VIP 带宽与定制路由）。年付价格已在各套餐中标明。

订阅导入成功但无法联网怎么办？

先确认系统时间准确、没有多个代理软件抢占系统栈。接着更新订阅、更换同区域节点，并把模式改为规则而非全局做对比。若仅某个网站失败，多半是分流规则问题，而不是云魂整网中断。旗舰版用户可通过优先工单提交节点名称与错误日志。

是否支持流媒体解锁和游戏加速？

基础版支持基础流媒体；旗舰版强调全节点原生解锁，并包含 IPLC 专线游戏优化。实际效果与内容平台风控、节点负载有关，连接后请选择对应分组，不要用普通中转节点强行播放高码率内容。

设备数超限或流量用尽会怎样？

同时在线超过套餐台数时，新设备可能无法握手或旧会话被踢出。流量用尽后加速会停用，次月重置或升级套餐后恢复。团队版适合共享场景，但仍建议为关键设备保留固定配置文件，减少反复登录。

如何确认自己访问的是云魂官网？

认准品牌名「云魂」与本站套餐、客户端说明是否一致。官方下载只指向客户端选择专区与操作说明中的步骤，不会以附件形式索要订阅或远程桌面。收藏本页锚点结构即可快速回到套餐、下载与问答。
